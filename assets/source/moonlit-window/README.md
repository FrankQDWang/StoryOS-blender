# Moonlit window shared atlas

Created 2026-10-04 with the built-in ImageGen tool from the user-approved room proposal. Actual generation timestamp: 2026-10-04 15:12:12 UTC (23:12:12 Asia/Singapore). Full prompt: `prompt.txt`; original tool path, reference SHA, sizes and output SHA: `provenance.json`.

- `source.png`: untouched native 1254 × 1254 output, opaque.
- `atlas.png` / `atlas.webp`: identical 1024 × 1024 RGB pixels; WebP uses lossless encoding.
- `derive.mjs`: reproducible extraction/resize/packing with project-local Sharp. It corrects ImageGen's approximate region divisions to exact atlas coordinates without painting any content.

Pixel coordinates (top-left origin): sky / distant ridges x0–767, y0–1023; moon x768–1023, y0–255; optional bark x768–1023, y256–1023. Inset UV samples by at least half a texel to avoid bleeding across the tile boundaries.

## Visual inspection

Inspected both the native output and final 1024² derivative at full image size. Quiet blue sky, thin cloud texture, low-contrast lower ridges / distant forest, pale detailed near-full moon with a wisp of cloud across the lower face, and dark bark match the required assets. No room, frame, text or stars were generated. The generated moon occupies about 80% of its square tile (requested 70%); compensate through runtime plane size so its visible scene diameter matches the approved 8–12% window-width target. Its black surround can be masked in the material; the cloud outside the lunar disc will require a conservative brightness cutoff. This image is a texture asset, not visual acceptance of the assembled 3D scene.

The entire atlas is opaque RGB. A runtime alpha mask must be derived from lunar brightness or its black exterior. This asset adds no requirement for a transparent sky material.

## Runtime geometry

`window-vista.blend` and `public/assets/models/window-vista.glb` are generated by `scripts/build_window_vista.py` (Blender 5.2.2 LTS, seed 10429). `geometry.json` records the export identity. The scene contains closed conifer boughs, solid tapering trunks/branches, two forest depth layers, a continuous ridge, a large opaque sky, a far moon decal, sill joints and one very faint glass surface. Atlas color is shared by sky/moon/bark; there are no additional light sources or animated exterior effects. `WindowVista.jsx` supplies the runtime materials and disables ray picking on decorative meshes. The original room and its baked lighting are not regenerated.

Rebuild: `blender --background --factory-startup --python-exit-code 1 --python scripts/build_window_vista.py`, then `python3 scripts/asset_manifest.py` and `npm run build`.
