# Approved-window fidelity correction

The first runtime was rejected because its composition and foliage differed from the selected reference. Reference remains `design/round-12-moonlit-window/02-room-proposal.png`; no new direction was selected.

- `sky-source.png` and `sky.webp`: built-in ImageGen using the approved window crop; combined soft moon, thin clouds and layered mountains. Prompt/SHA in `provenance.json`. The 1024² texture is mapped to a large fixed opaque background. UV rows align the mountains while preserving the moon's circular shape; a shader extends edge colors smoothly beyond the image to avoid clamp streaks in close views.
- `pine-spray-source.png`, `pine-spray.png`, `pine-spray.webp`: built-in ImageGen fine pine twig with true alpha. Prompt/SHA in `pine-spray-provenance.json`. Used as fixed intersecting needle sprays around solid branches and closed tree cores, not camera-facing full-tree billboards. Alpha testing avoids transparent sorting; nearby foliage retains source needle color, distant foliage uses layer colors.
- Bark: losslessly cropped from the first approved-direction atlas using `derive-bark.mjs` (256×768). Runtime does not download the old sky/moon atlas.

Geometry stays in `assets/source/moonlit-window/window-vista.blend`, generated by `scripts/build_window_vista.py`. The generator batches mesh arrays before creating Blender objects, and removes only unused normal streams from unlit exported layers; positions, triangles and UVs remain unchanged by that export step. The GLB, three runtime textures and source/provenance are recorded in `assets/manifest.json`.

Runtime texture destinations: `public/assets/textures/window-sky-v2.webp`, `window-needles-v2.webp`, `window-bark-v2.webp`. No added light, exposure change or room rebuild.

WindowVista uses the window aperture as a conservative native frustum-culling bound for each exterior mesh. This prevents off-screen sky/forest submissions during book focus/opening while keeping the visible window unchanged. The sphere is transformed to each mesh local space; Three evaluates it with the current camera during rendering, so no previous-frame visibility state is used.

The texture URL tuple is shared by `useTexture(TEXTURES)` and `useTexture.preload(TEXTURES)`. R3F keys grouped loads by `[loader, ...urls]`; individual preload calls do not populate that grouped entry.
