## 已确认与待验证

用户最新原话：“R12 ·《魔弦传说》微缩布景实拍 这个接近，其他的都不是，请总结和分析我可能喜欢的元素，继续查找，谢谢”。

R12 是上一批唯一正向线索，程度是“接近”，不是整套方案批准。其他 11 张已展示图被否定，R14 未展示。保留小型私人作家的魔法藏书室、低元素密度、不要阳光与已确认功能核心。

目前最有力的方向假设：**有可信体积与光影、能看出制作痕迹的手工奇幻布景**。以下均为从图片作出的分析，不能写成用户已确认偏好：

| R12 中观察到的特征 | 可能吸引用户的原因 | 仍需区分 |
| --- | --- | --- |
| 地面、屋顶和木框架形成清楚纵深，家具分成少数几组 | 空间本身有存在感，视线有停留和通行的余地 | 喜欢这种组织，不等于喜欢巨大房间或日式结构 |
| 木、纸、布呈现哑光触感，表面有绘制、雕刻与磨损的痕迹 | 像经过美术设计的实体模型，既有触感也有艺术化 | 用户所说“不要太写实”不宜再被机械等同于厚边、圆润或鲜艳 |
| 墙面与屏风上的大幅绘画占据视觉重点 | 故事气氛可以由少数大图案承载 | 不代表照搬原作画面、人物或东方题材 |
| 赭黄、深棕为主，少量灰绿、暗红与冷色 | 配色有主次，视觉信息较集中 | 暖色和木色尚未单独获确认；旧照片 C 不恢复为目标 |
| 光影让家具落在空间里，部分区域明亮，部分安静 | 体积可信，带有电影布景的气氛 | 本项目“不要阳光”仍有效，R12 的具体照明不直接照搬 |

R12 仍有散落纸张、装饰和做旧细节，并非极简空间。“低密度”的可借鉴点是主要物件的数量、分组和完整空地；不应宣称它完全没有杂物。减少独立道具可能节省部分制作，但材质与光照仍需设计，暂不承诺制作时间或性能。

创作来源也提供了一条线索：导演 Travis Knight 谈到斋藤清木版画对《魔弦传说》的影响，包括清楚的图形、有限的配色和纹理处理。S14 用来比较这种视觉组织，不表示下面这幅具体作品就是电影的直接参考。[FilmInk 导演访谈](https://www.filmink.com.au/exclusive-travis-knight-on-kubo-and-the-two-strings-part-4/)
