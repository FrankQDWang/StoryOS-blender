## 每张图的参考边界

- **R01**：墙上挂件较密；只参考造型和色彩，不照搬陈设数量。
- **R02**：现代卧室布局仅供私人感参考；不是古典魔法藏书室定稿。
- **R03**：画面偏暗，木结构仍较可信；只用于确认夜色、留白与私人感。
- **R04**：只研究魔法光源与亲切感，不引入现成角色。
- **R05**：像素画不是最终渲染方式的决定；不照搬双层建筑和巨大角色。
- **R06**：陈设密度过高，不作为空间布置目标；仅比较手绘风格与物件造型。
- **R07**：画面包含店铺、街景和大量 UI；只参考 3D 卡通程度、比例和夜间配色。
- **R09**：桌面可继续精简；不采用蜘蛛网和所有道具。
- **R10**：高挑空间与明亮上部不符合当前小型无阳光目标；仅作局部造型/魔法光参考。
- **R13**：只选少量主要物件；不照搬书堆、药瓶、落纸密度。
- **R11**：儿童绘本感较强、藏书仍密集；不是默认推荐方向，不采用亮窗作为目标。
- **R12**：用户唯一评价为“接近”的图片。空间组织、手工纹理、配色、图绘装饰与照明均可继续逐项分析；不预先排除或认定具体局部，日式建筑与房间尺度也尚未确认。
