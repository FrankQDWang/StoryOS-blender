# 薄云小月·月夜深林：实施与验收

选图：`design/round-12-moonlit-window/02-room-proposal.png`。用户“可以认可”确认样稿；运行效果的用户最终认可另行记录。起点 `2889b4c02ed748aa0c5589b7dbf79d7ac6c9c0f5`，累计基线 `eedd74593e883aba070e4fa97dfc1e0079f433cb`。

## 实现

独立 `WindowVista.jsx` 与 Blender 窗景；只隐藏原房间的 NightGlass / NightSilhouetteFar / NightSilhouetteNear 三类网格。近枝为闭合实体，中景森林分两层，远处是不透明天空和山脊，近满月与薄云使用同一图集。窗台/窗框补少量接缝，玻璃透明度 0.018。月亮固定在远处，不绑定相机，不产生新灯光。

窗景与房间放在同一个 Suspense 中，完整加载后才显示就绪。装饰禁用 raycast，不参与碰撞；外景独立冷色且不受室内暖雾影响。原房间 GLB、光照图、所有书本/手部资源与控制逻辑、相机和后处理保持。241 份既有运行源/资产中只改 Scene.jsx；身份核对见 `evidence/moonlit-window/final/build-identity.json`。

新增 GLB 1,897,824 字节、9 个网格/材质、99,437 三角形；1024² 无损 WebP 图集 810,346 字节。图集为内置 ImageGen 参考批准样稿生成，原图/提示词/确定性打包脚本/哈希在 `assets/source/moonlit-window/`。Blender 5.2.2 LTS 源文件、随机种子和导出脚本均保留。没有重建全屋。
