# 五款私人手稿与作品生命周期

确认：2026-10-03。实施：2026-10-04。历史交付版本：0.1.5-preview.1。

2026-10-04后续：用户否定本版材质还原并指出内页重复书名。视觉判断由[软皮修正记录](25-soft-leather-correction.md)覆盖；本页性能结果只属于preview.1。

用户认可线程《评估项目优化空间》最后交付的五款外观，并在本对话确认自动分配、删除消失和空架规则。选图沿用 `design/round-10-five-book-materials/` 的 `warm-umber.png`、`muted-pine.png`、`slate-blue.png`、`smoky-plum.png`、`warm-ochre.png`；运行外观以它们为参照。

## 实现

- 五个固定材质身份依次为暖棕、灰松绿、蓝灰、烟紫褐、麦褐。创建成功时选首个未被在架作品占用的款式及首个空位，保存 `materialId`、颜色和 `slot`。
- 新浏览器书库为空。现有 v1 本地作品补齐材质身份，原作品、描述、颜色、位置和最近作品保留；空库刷新不会生成示例。
- 删除入口位于全部作品中，确认后同步移除书本和列表项，释放位置和款式；其他书不重排，也不自动将列表书补上架。
- 五个位置已满时，新作品留在全部列表并提示，可搜索/直接进入；其外观复用五款，不新增模型。
- 仍共用原 `story-book.glb`。运行时隐藏旧金框、金属角和徽章，将书脊带改为皮革。两张768×768纹理共315,662字节，通过五组色调/纸色/粗糙度/凹凸参数区分。
- 书名与简介从实际作品动态绘制。静态页和翻动页共用纸页配置，纸背使用正确方向的装饰笔迹，避免镜像作品文字。生成笔迹只是材质装饰，不是作品正文。
- 内置 ImageGen 一次图集生成，生产处理脚本、实际提示词和输入输出哈希在 `assets/source/manuscript/` 与相邻提示词文件。

## 视觉检查

Chrome已检查五款闭合/打开近景、全景、第一位抬封面正侧面。首轮标题偏小、皮纹偏弱、翻页背面镜像已修正。助手认为五款在现有夜间书房中协调，动态书名、朴素旧皮和暖纸手稿方向成立。不同展示位的既有光照使第二、第三款比炉边更暗；本轮保持房间灯光。

房间GLB、原书GLB、手部GLB、房间布局、手部组件、火焰和开合时间轴与 `eedd745` 字节一致。运行书页增加表面贴图，未改变页张曲面函数或手部动作。本轮实现效果的用户视觉评审尚未进行。

## 性能

基线为当前根工作区 `eedd745` 的冻结生产构建；候选使用相同生产构建方式。Chrome 154.0.8037.93、同机arm64、1512×751、DPR 1、相同五书数据与网络。初始各组3个样本；受控网络暖缓存因手部时点波动补到5个，所有原始样本保留。

| 首屏比较 | 基线中位数 | 新版中位数 | 增幅 |
| --- | ---: | ---: | ---: |
| 本机冷缓存 | 989 ms | 1051 ms | 6.21% |
| 本机暖缓存 | 1026 ms | 1076 ms | 4.85% |
| 20 Mbps / 50 ms，冷缓存 | 19386 ms | 19530 ms | 0.75% |
| 20 Mbps / 50 ms，暖缓存 | 1049 ms | 1114 ms | 6.17% |
| 每次全新Chrome进程和空profile，本机冷启动 | 1094 ms | 1148 ms | 4.97% |

首次手部绘制、进入工作区、返回及复开各比较组中位数也在10%以内；最高增幅9.02%（受控网络暖缓存首次手部着色绘制，67.6→73.7 ms）。完整开书到工作区仍约3.502秒。上述为同机固定口径中位数；原始首次候选本机冷缓存有1.928秒单样本，未删除，以新增全新进程/空profile配对检查首轮缓存差异。

首屏要求实体绘制和GPU完成，手部指标取实际着色蒙皮绘制调用，不把DOM出现或资源字节数当作渲染完成。详细脚本和口径见 `tools/book-check/README.md`；完整结果在 `evidence/five-books-20261003/benchmark-{raw,summary}.json`、`fresh-browser-start.json` 与 `build-identity.json`。主流程及实际连续画面以同目录的smoke/opening记录为准。
