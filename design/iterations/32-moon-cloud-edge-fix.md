# 窗边月云矩形边缘修正

用户反馈：远处正常，自由漫游走到窗边时，月亮右上方暗云呈方形。用户近/远参考图保存在 `evidence/moonlit-window/moon-square/user-near.jpg`、`user-distant.png`。

## 定位与修改

复现方式：独立无头 Google Chrome，1512×751、DPR1、五书，点击自由漫游，经 WASD 走到窗边并抬头。同机位临时替换天空材质采样，保留 before、clamp、feather 和局部放大图。原实现只在 UV 超过 0–1 后开始过渡，纹理边缘云色被 ClampToEdge 延展，越界处和中心列填充天空之间显出矩形边缘。去掉过渡只保留 clamp 会产生长条，改为边界内平滑混合后矩形消失。

`apps/web/src/WindowVista.jsx` 仅修改天空 shader：在图内横向0.28、纵向0.16范围内渐隐到原中心列天空色，图外直接使用同一延展色。月面所在中心区完整保留原贴图。维持两次纹理采样，不新增贴图、材质、几何、灯光、透明层，不更改原图或Blender源。
