# 薄云小月·月夜深林：已确认实施计划

日期：2026-10-04。用户已要求执行本计划。当前阶段为冻结基线、制作视觉样稿；用户认可样稿后进入三维制作。

## 目标

把现有较平的两层树影升级为近枝、中景森林、远处山林与夜空三个明确层次。全景增加纵深，靠窗精致，左右漫游可信。保持昏暗室内、暖炉冷窗、房间构图、书桌位置、五台与已认可书本效果。

完成须同时满足：助手对实际 Chrome 画面与连续帧的视觉检查通过，核心主流程通过，加载延迟增幅不超过10%。

## 已确定视觉方案

- 月亮采用用户选定的薄云遮掩近满月。首页窗户上半部偏右，避开窗格交叉点；直径约窗宽10%，可在8%–12%微调。柔和冷灰白、浅月面纹理、淡薄云，不产生明显光晕或室内新增补光。
- 近景一至两组有厚度、不对称的枝干偏置窗侧，保留朝远处看的空隙。
- 中景两层高低、疏密不同的林冠，自然遮挡，消除重复排列。
- 远景低对比林线/山脊和暗蓝天空，薄雾以色层表现，月亮和薄云合入远景。
- 窗框/窗台轮廓和尺寸保持，补少量接缝、边缘磨损、粗糙度变化。玻璃只用轻微表面反光/痕迹。
- 首轮全部静态，不新增实时透射、动态反射、体积雾或阴影灯，不改变曝光和后处理。

## 实施顺序

1. 冻结 `2889b4c02ed748aa0c5589b7dbf79d7ac6c9c0f5` 生产构建和同机位、同五书截图。以真实首页为底图制作一版完整房间效果图和窗边局部；**用户认可样稿后作为三维制作对照**。
2. 独立 Blender 制作近景枝干、中景轮廓；不透明远景背景。纹理优先一张1024²图集，仅实际靠窗清晰度不足才升2048²。
3. Scene 中隐藏旧 NightGlass / NightSilhouetteFar / NightSilhouetteNear 网格，接入独立窗景组件；原房间 GLB 和烘焙光照保持。窗框细节用独立附加几何，避免重建/重烘焙全屋。
4. 外景保持现有相机裁剪范围内，使用自己的冷色色层，不受室内暖雾影响；装饰不参与拾取和碰撞。窗景与房间共同完成后才报告就绪，实际首屏观察须包含窗景绘制。
5. 静态效果成立后完成正式生产预览的视觉、主流程及性能验收，开发首页只作一致性抽查。

不改变公开接口、作品数据结构和存储；内部新增场景组件、窗景资产及制作来源。
