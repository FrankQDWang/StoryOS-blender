## GPU测量校准

EXT_disjoint_timer_query_webgl2返回可用，但分段累加约262ms/帧，与55FPS矛盾；同步完整帧墙钟6–9ms、查询报告19–31ms。空查询0，clear查询亦远高于完成墙钟。因此baseline-stable中的WebGL GPU字段全部无效，不用于验收。`gpu-calibration/`保留反证。

改用已有Xcode Metal System Trace，筛选该测试Chrome GPU PID，按真实场景采样墙钟窗口裁剪Active Vertex/Fragment/Compute区间、重叠只计一次，再除以同窗口实际WebGL场景渲染数。包含浏览器合成；不使用Instruments的“Frame #”（实际是命令缓冲序号）。原生轨迹放项目.cache，导出表与窗口保留。

首页原生样本：3.502s、210实际渲染帧、GPU活跃3282.244ms，即15.630ms/渲染帧，GPU占用93.72%。五场景原生数据见下表。GPU按场景总量测量；阴影/主场景/后处理拆分采用CPU提交实测，不混用两者。

## 阴影是否变化

| 对象 | 投影 | 闲置期间变化 |
|---|---|---|
| 房间非发光网格、炉内木柴 | 是 | 几何和变换固定 |
| 五书SoftBook | 是 | 已有相同time跳过变形；不重做 |
| 开书/手/创建飞行的书 | 是 | 动画期间逐帧变形或移动 |
| 火焰、火星、Sparkles、魔法环 | 否 | 可见动画继续，不影响阴影图 |
| 窗外景物 | 否 | 不影响室内阴影图 |
| 桌灯512² | 是 | 坐标、范围固定 |
| 炉火点光1024² | 是 | 仅intensity变化，坐标/范围固定；强度在主场景照明时使用 |

首页运行时61投影网格、2投影灯。创建、删除、书集合/外观替换、开书与手卸载必须使阴影失效；动态期间逐帧刷新，结束也刷新一次。初次Suspense资源加载后必须刷新。漫游不改变投影几何或光源，但完整Chrome漫游仍需验收。
