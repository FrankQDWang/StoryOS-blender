## 实际测到什么

末节与封面平面的角度全部为21.6–22.1°，替代原候选约54–77°向封面戳的形态。修正后的实际相邻骨轴弯曲方向全部正向，角幅约1.5–10.7°；这是骨轴几何描述，不是标准人体关节测量或生理认证。

最终皮肤位置使用 Blender evaluated mesh 复核，非仅骨骼尾端。解析蒙皮与实际 Blender 表面在食/无名/小指的最大误差约3e-7作者单位；中指受邻近骨权重影响，解析误差约2mm，因此最终中指接触数据采用实际 evaluated mesh。

在理想下表面平面 z=.1595 的检验中：

- 低位中指最高点 y≈-.4704、z=.1595；食指最高点 y≈-.4896，距该平面约1.9mm。
- 高位中指最高点 y≈-.4638，距平面约0.67mm；食指最高点 y≈-.4915、z=.1595。
- 无名指随行，距面约1.0–1.3cm；小指约2.2–2.4cm，不强行四指同面。

指腹中心比骨骼尾端均值后退约1.5–2cm。因此伸展后继续把 bone-tip mean 放在 y=-.480 会把实际指腹推到封面之外。最终锚点退到约 -.465，兼顾前沿唇边与纸块前沿。

## 接入后仍需检查

封面前沿有倒角，食指最高点位于倒角区；z=.1595 是平面代理，不能当作精确封面三角网碰撞证明。中指接触最明确，食指是靠近倒角的辅助承托。需要主线程在真实导出后的低位/高位和连续动作中检查接触、纸块穿插、两指分离、拇指是否仍显僵硬，以及新的掌向和前臂连接。当前结果解决了指节反折和“指尖垂直戳封面”的主要数值问题，没有宣称整段动作视觉通过。
